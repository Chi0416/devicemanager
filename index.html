            自動抄表說明

            張數有兩種送法。

            • 機器自己寄信機器每月 1 號把張數寄到你的 Gmail，不用別的電腦
            • 抄表程式客戶那邊一台一直開著的 Windows 電腦，每天回報張數和碳粉

            1. 試算表（兩種都要，用電腦做一次）

            照設定裡「自動抄表」的設定步驟做：第 5 步的部署兩種都會用到，第 6 步的密語只有抄表程式要。

            2. 機器自己寄信

            照「」設好，每月 1 號寄出；試算表上的程式每小時讀信，寫一筆上個月的帳。5-866-112 寄測試信（不算帳）。

            3. 抄表程式

            1. 程式資料夾裡的「設定.txt」填網址（設定裡的讀信網址）和密語
            2. 有 Python 的電腦：pip install puresnmp，點「抄表.pyw」；沒有的：在有 Python 的電腦點「打包.bat」，把「發佈」裡的「抄表」資料夾整個複製過去（例如 C:\抄表），點「抄表.exe」
            3. 輸入機器的 IP →「新增」→ 勾「開機自動執行」
            4. 按「提交計數器」試一次，試算表會多一個「最新回報」分頁
            • 每天背景回報一次張數和碳粉，存在試算表的「最新回報」分頁，一台一列，只留最新一次
            • 提交計數器客戶按了就馬上回報一次
            • 抄表設備詳情的「最新回報」寫張數和幾天前，按「抄表」帶入日期和張數，結算月份自己選
            • 設備清單序號右邊寫多久以前回報，超過 7 天橘字
            • 總覽超過 7 天沒回報的列在「要處理」的「回報停了」

            燈號

            • 綠讀好了、送出了
            • 黃讀取中、送出中
            • 灰連不到
            • 紅有問題，看視窗最下面那行

            背景不用開著視窗，開機登入後自己跑。停掉：視窗裡取消勾選「開機自動執行」，或工作管理員 →「啟動應用程式」→「抄表」→ 停用。

            4. 出問題時

            • 「抄表」沒有新的列寄信的每小時才讀一次：試算表上方「自動抄表」→「現在讀信」
            • 備註寫「序號 X 對不到設備」App 裡登記這個序號，下次讀信時自動補上
            • 連不到IP 對不對、機器有沒有開、SNMP 有沒有開
            • 抄表.exe 不見了（被防毒刪掉）Windows 安全性 → 病毒與威脅防護 → 管理設定 → 排除項目 → 新增「資料夾」，選抄表那個資料夾（要系統管理員），再把資料夾重新複製一次
            • 還沒有密語、密語不對試算表上方「自動抄表」→「密語」，重新複製到設定.txt
            • 試算表上的程式是舊版、找不到指令碼函式「複製程式」重貼、存檔，再「管理部署作業」→ 鉛筆 → 新版本
